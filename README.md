# CodeAlpha_StudentGradeTracker
🎓 Student Grade Tracker

A simple Java console-based application for managing student marks and calculating their academic performance.

---

📌 Project Overview

The Student Grade Tracker allows users to add multiple students and enter their marks in:

- Mathematics
- Java
- English

The application then calculates and displays each student's:

- Total marks
- Average marks
- Highest mark
- Lowest mark
- Grade

---

✨ Features

- ➕ Add multiple students
- 📝 Store student names and marks using "ArrayList"
- ✅ Validate marks between 0 and 100
- 🧮 Calculate total and average marks
- 📈 Find the highest mark
- 📉 Find the lowest mark
- 🏆 Assign grades automatically
- 📊 Display student information in a formatted table
- 🔄 Menu-driven console interface

---

🛠️ Technologies Used

- Java
- "ArrayList"
- "Scanner"
- "Math.max()"
- "Math.min()"
- Loops
- Conditional statements
- Switch expressions
- Formatted output using "printf()"

---

📊 Grading System

Total Marks| Grade
250 – 300| A
210 – 249| B
180 – 209| C
150 – 179| D
120 – 149| E
Below 120| F

«Note: A student must score at least 33 marks in every subject to receive grades A–E. Otherwise, the student receives an F.»
